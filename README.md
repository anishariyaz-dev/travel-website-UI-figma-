## ✨ Overview

This project explores a modern travel website experience with a bold black-and-yellow color palette, immersive destination photography, and a clear visual hierarchy.

Key Sections
- **Navigation:** Main menu, login, and sign-up
- **Hero Section:** Headline, call-to-action buttons, and destination previews
- **Search Bar:** Destination, travel dates, members, and pickup location
- **International Destinations:** Turkey, Paris, and Thailand
- **Google Reviews:** Customer testimonial carousel
- **South India Exploration:** Destination gallery featuring Coorg, Kerala, Hyderabad, and more
- **Travel Statistics:** Ratings, travelers, tour captains, and destinations

## 🎨 Design Highlights

- Black background with yellow accents
- Serif section headings paired with clean sans-serif typography
- Rounded destination cards and circular image previews
- Carousel-style controls and pill-shaped buttons
- High-contrast layout with photography as the focal point

## 🛠️ Tools Used

- **Figma** — UI design and layout
- **Stock photography** — Destination imagery

## 📱 Design Approach

Designed with a desktop-first layout, prioritizing visual hierarchy, destination discovery, and an engaging browsing experience.
